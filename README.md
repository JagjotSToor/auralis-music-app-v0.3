# AURALIS by ZHEHR STUDIO — v0.3 (Upgrade drop A)

Built on the working v0.2. Nothing was rebuilt; library, playback, queue, playlists, favorites, search and
notification controls are untouched.

## New in v0.3
- 13 themes (Obsidian, Amber, Crimson, Electric Blue, Violet, Emerald, Ice, Cyber, Midnight + System/Dark/AMOLED/Light),
  custom accent (swatches or hex, auto-adjusted for contrast), optional film grain.
- Motion: Minimal / Balanced (default) / Cinematic. Short startup animation (skipped in Minimal).
- First-launch "Choose your Home" with 8 presets; Home layout screen (show/hide, reorder, card size).
- Hide song (restore from Settings > Hidden songs). Hidden songs never appear in the library, search, shuffle or resume.
- Recording detection (call / voice / screen) with a Recordings tab, include/exclude settings and folder correction.
- Now Playing: swipe artwork for previous/next, swipe down to close. Queue: Shuffle button.
- Settings redesigned into categories; About shows ZHEHR STUDIO and owner.

## Database
Room v2. A migration keeps favorites, playlists and history. On first launch after the upgrade the library is
re-evaluated once so recordings are detected.

## Next drops
B: wallpaper system, lyrics, equalizer, fuzzy/unified search. C: genres, queue drag-reorder, swipe actions, vocal-reduction research.
